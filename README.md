# CareerFlow AI (Static Web App)

CareerFlow AI is a vanilla HTML/CSS/JavaScript web app for students and early-career job seekers to:

- tailor resumes using ATS-style keyword analysis,
- generate cover letters,
- create networking/hiring-manager outreach messages,
- and track job applications in a dashboard.

## Tech stack

- HTML
- CSS
- JavaScript (no framework)

## Run locally

Open `index.html` directly in your browser, or serve the folder with any static server.

## Deploy to GitHub Pages

This repo includes `.github/workflows/deploy-pages.yml`.

1. Push to `main`.
2. In GitHub repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**.
3. The workflow deploys the static site automatically.
